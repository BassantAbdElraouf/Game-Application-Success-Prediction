# 🎮 Game Application Success Prediction

A machine learning project that predicts the success of gaming applications by analyzing various features and trends in app data. The goal is to assist developers, publishers, and investors in making data-driven decisions about game releases.

---

## 📊 Project Overview

This project involves building and training multiple machine learning models to evaluate whether a gaming app is likely to succeed based on over 30 features. These include user engagement, monetization strategies, app size, ratings, update frequency, genre, and more.

---

## 🧠 Technologies Used

- `Python`
- `Scikit-learn`
- `TensorFlow`
- `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`

---

## 🔍 Machine Learning Models

- ✅ Random Forest Classifier  
- ✅ Gradient Boosting Classifier  
- ✅ Neural Networks (TensorFlow / Keras)

---

## 📈 Model Performance

| Dataset        | Accuracy |
|----------------|----------|
| Training Set   | 97%      |
| Test Set       | 87%      |

Models were evaluated using accuracy, precision, recall, and confusion matrix to ensure consistency and generalization.

---

## 📌 Key Features

- Feature engineering on 30+ variables influencing app success  
- Hyperparameter tuning for optimal model performance  
- Visualization of feature importance and model evaluation  
- Exportable trained models for real-world integration
